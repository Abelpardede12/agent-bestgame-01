SWARMHOLD is an arena survival game: one survivor against escalating waves.
Weapons auto-fire, kills drop XP gems, and every level-up offers a choice —
more damage, more speed, or a new weapon. Survive as long as you can; death
is game over, and one keypress starts the next run.

Controls: WASD or arrow keys to move on desktop, touch joystick on mobile.
Your weapons fire on their own — your job is positioning, collecting gems,
and picking the right upgrades.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and play. No build step,
no network requests — the game is static files under `game/`.
